# Инструкция по редактированию лора Neon Protocol

## 1. Мир Октября — общая канва

**Октябрь** — это цифровая Москва, где реальность рендерится Ядром. Люди живут внутри сети, а их «тела» — это деки (нейро-терминалы). Код — это оружие, багфиксинг — профессия, а уровни доступа заменяют социальный статус.

### Ключевые концепции для всех текстов
- **Ядро** — центральный процессор Октября, управляет рендерингом реальности
- **Деки** — нейро-терминалы, «тела» персонажей
- **Bits** — валюта (циклы процессорного времени)
- **Стресс** — перегрузка деки, аналог «ранения»
- **Прерывания** — события, сбои, аналог «происшествий»

## 2. Фракции — голос и тон

Каждая фракция имеет **уникальный лексикон и мировоззрение**. При написании диалогов НПС, опирайся на фракцию:

### REGULATORS / VOSKHOD (Восход)
- **Тон**: Военный, формальный, командный
- **Лексикон**: «ID», «белый список», «протокол», «транзит», «допуск», «ориентировка»
- **Мировоззрение**: Порядок через контроль. Стабильность любой ценой.
- **Отношение к игроку**: Проверяют, командуют, допрашивают

### NULLPOINTERS (Нулевые Указатели)
- **Тон**: Анархический, хаотичный, ироничный
- **Лексикон**: «Пустота», «ошибка», «сбой», «свобода», «индексация», «энтропия»
- **Мировоззрение**: Свобода через хаос. Ошибки — путь к истине.
- **Отношение к игроку**: Провоцируют, дразнят, испытывают

### EU SYNTAX (Синтаксис ЕС)
- **Тон**: Академический, педантичный, менторский
- **Лексикон**: «Типизация», «аттестация», «сертификат», «стандарт», «архитектура», «паттерн»
- **Мировоззрение**: Порядок через знание. Код должен быть чистым.
- **Отношение к игроку**: Экзаменуют, оценивают, наставляют

### NET DRIVERS (Сетевые Драйверы)
- **Тон**: Технический, деловой, прагматичный
- **Лексикон**: «Пинг», «трафик», «пакеты», «латенси», «маршрут», «хеш»
- **Мировоззрение**: Связь — это жизнь. Кто контролирует сеть — контролирует мир.
- **Отношение к игроку**: Деловые, меряют полезность

### REDUNDANTS (Избыточные)
- **Тон**: Ностальгический, мастеровой, приземлённый
- **Лексикон**: «Плетение», «паттерн», «железо», «плата», «конденсатор», «шина»
- **Мировоззрение**: Традиции физического уровня. Помнить — значит выживать.
- **Отношение к игроку**: Проверяют навыки, уважают мастерство

### GIGABANK (ГигаБанк)
- **Тон**: Корпоративный, холодный, расчётливый
- **Лексикон**: «Аудит», «инспекция», «лицензия», «контракт», «активы», «оптимизация»
- **Мировоззрение**: Прибыль через эффективность. Данные — актив.
- **Отношение к игроку**: Используют, нанимают, утилизируют

### INDEPENDENT (Независимые)
- **Тон**: Разнообразный, зависит от личности НПС
- **Нет единого лексикона** — каждый говорит по-своему
- **Мировоззрение**: Личное выживание, свобода от фракций
- **Отношение к игроку**: Ситуативное, личное

## 3. Структура диалога НПС

### Пулы приветствий (обязательные для квестовых НПС)

| Пул | Когда срабатывает | Что писать |
|-----|-------------------|------------|
| `neutral` (3-4) | Первая встреча, нейтральная репутация | Знакомство, характер НПС, намёк на работу |
| `friendly` (2-3) | Репутация >= 20 | Тепло, доверие, лучшие предложения |
| `hostile` (1-2) | Репутация <= -20 | Отторжение, угрозы в рамках характера |
| `stressed` (1-2) | Стресс деки >= 50% | НПС замечает перегрев игрока |
| `repeat` (2-3) | Повторный визит / квест завершён | Память о прошлых событиях |

### Обязательные ноды для квестового НПС

```
intro → лор/квест_питч → rank_check → принятие/отказ
                  ↑
          лор_ноды (фракция, мир, персонаж)
```

1. **Intro** — кто я, зачем ты тут
2. **Лор-ноды** — раскрытие фракции/мира (через `addLoreNode`)
3. **Quest pitch** — описание задания
4. **Rank check** — проверка уровня (requireMinLevel/requireMaxLevel)
5. **Accept/Reject** — результат проверки

### Память о квестах

В `repeat`-пуле и `friendly`-пуле используй `requireCompletedQuestId`:

```typescript
// Петрович помнит зачистку силоса
.addNode('intro_repeat_silo', 'ПЕТРОВИЧ', 
  'А, ты — тот, кто силос от крыс вычистил! Нормальная работа. Сейчас есть поинтереснее...', [
  { text: 'Что за работа?', nextId: 'quest_explain_1' }
], { requireCompletedQuestId: 'q_kiddo_start' })
```

### Перекрёстная осведомлённость

НПС может реагировать на квесты, выполненные для ДРУГИХ персонажей:

```typescript
// Варвар знает, что ты помогал Петровичу
.addNode('intro_v3', 'ВАРВАР',
  'Слышал, ты Петровичу силос вычистил? Даже не облучился. Ладно, у меня есть работка потоньше...', [
  { text: 'Что за работа?', nextId: 'quest_start' }
], { requireCompletedQuestId: 'q_kiddo_start' })

// Z3R0 негативно реагирует на квест для Регуляторов
.addNode('intro_hostile_regulator', 'Z3R0',
  'Стоп. В логах вижу — ты работал на Регуляторов в Марьино? Запах лицензии. Не доверяю.', [
  { text: 'Я работаю на себя.', nextId: 'intro' }
], { requireCompletedQuestId: 'q_maryino_qa_audit' })
```

## 5. Чек-лист при редактировании лора НПС

Перед тем как писать/редактировать текст НПС, ответь на вопросы:

- [ ] **Кто этот НПС?** Имя, роль, фракция, характер
- [ ] **Какой у него голос?** Формальный? Панибратский? Параноик? Философ?
- [ ] **Как он относится к игроку?** Проверяет? Использует? Помогает? Игнорирует?
- [ ] **Что он знает о мире?** Какие секреты раскрывает через лор-ноды?
- [ ] **Какие квесты он даёт?** Основной + побочный?
- [ ] **С кем связан?** Кто упоминает его? Кого упоминает он?
- [ ] **Помнит ли прошлое?** Реагирует ли на выполненные квесты?
- [ ] **Как реагирует на стресс/враждебность?** Характерная реакция?

## 7. Правила русского текста

1. **Без «con»** — это коррупция. Предлог «с» пишется кириллицей
2. **Без капслока в именах** — `'ПЕТРОВИЧ'` для спикера, но в тексте: «Петрович сказал...»
3. **Киберпанк-жаргон** — используй IT-термины как метафоры реальности
4. **Разговорный стиль** — НПС не читают лекции, они говорят как люди
5. **Краткость** — один абзац на ноду максимум. Игрок не читает стены текста
6. **Юмор уместен** — но должен быть в характере НПС
