# Neon Protocol — питч продукта

**Moscow Zero** — киберпанк-платформа, где один аккаунт ведёт в три разных опыта: одиночную RPG на карте Москвы, кооперативную карточную «симуляцию релиза» и полноценный онлайн-стол для настольной RPG **Carbon 2185**.

Одна кодовая база, один бэкенд, общая авторизация и синхронизация прогресса. Игрок выбирает режим на входе — как вкладку в сервисе, а не как отдельную игру.

---

## Одной фразой

> **Neon Protocol** — это «операционная система» киберпанк-сессий: исследуй мегаполис в соло, отрабатывай командный спринт в коопе или веди стол НРИ с мастерскими инструментами уровня VTT — без смены платформы.

---

## Зачем это нужно

| Боль | Как решаем |
|------|------------|
| Настольщики разъезжаются по Discord + Roll20 + Google Docs + ботам кубиков | **NRI-лобби** — чат, листы, карта, кошелёк, сценарий и панель мастера в одном окне |
| Обучающие RPG и «айтишные» мемы живут в разных продуктах | **Solo + Coop** завязаны на профессии разработчика, квесты с рангами и карточный бой как метафора работы в IT |
| Запуск своего «игрового сервиса» дорог (БД, хостинг, команда) | **Fullstack на Node + SQLite** — деплой на App Platform за ноль на старте, SPA + API в одном процессе |

## Solo — Moscow Zero

**Сеттинг:** альтернативная киберпанк-Москва. Районы — отдельные модули контента с NPC, диалогами и квестами.

### Что умеет игрок

- **Карта мегаполиса** — ~18 игровых районов + хаб и спец-зоны; перемещение, контакты, фазы дня.
- **Диалоги с ранговой проверкой** — протокол «nos ne doros»: NPC не выдают опасные квесты новичку; иммерсивный отказ и подсказка, куда идти дальше.
- **Профессии и классы** — путь от «Скрипт-Киддо» к Java/Kotlin/DevOps/QA/PM и дальше по грейдам Trainee → Principal.
- **Карточный бой (CCG)** — колода, артефакты, враги по районам; прогресс синхронизируется с сервером.
- **Квесты и интел** — библиотека квестов, фрагменты разведки, привязка к `districtId`.
- **Аккаунт** — регистрация, JWT-сессия, сохранение состояния через `game/sync`.

### Что умеет контент-команда

- Модульный мир: `src/logic/world/<район>/` — NPC, объекты, диалоги изолированно.
- Валидаторы: `npm run test:world`, `npm run test:quests` — целостность диалогов и квестов до деплоя.

## Coop — полигон стартапа

**Сеттинг:** стартап на полигоне `coop_yard`. Четыре роли — **Admin, Developer, QA, PM** — тянут один общий «релиз приложения» против ИИ-оппонента.

### Что умеет команда

- **Ролевые колоды** — у каждой роли свой каталог карт; синергии между ролями, общие метрики угрозы и дедлайна.
- **Два формата пати** — симуляция с ботами на одном клиенте или живая пати с серверным состоянием матча.
- **Миссии полигона** — 25 слотов на тир + босс; junior-онбординг с фиксированными ТЗ и пул Codewars-стиля задач.
- **Рейтинг стартапов** — публичный топ, сохранение лучшего счёта в БД (`/neon_v1/coop/startup-rankings`).

### Пиллары дизайна

- Одна цель боя — «выпустить фичу»; разные рычаги, один счётчик успеха.
- PM как командное звено: решения по состоянию всей команды, не только своей руки.
- Прогресс ролей и открытые карты совместимы с общим sync аккаунта.

## NRI — онлайн-стол Carbon 2185

**Сеттинг:** настольная RPG в духе Carbon 2185 — характеристики STR/DEX/CON/INT/TEC/PEO, 27 навыков, 6 классов-архетипов, киберимпланты, экономика Neon City.

Мастер создаёт стол → игроки заходят по **invite-коду** → все работают в едином лобби.

### Вкладки лобби (игрок и мастер)

| Вкладка | Возможности |
|---------|-------------|
| **Чат** | Комната стола, личные сообщения, спам-бот (опционально), антиспам за вонлонги |
| **ICE** | Мини-игра взлома Gibson ICE, таблица лидеров стола, награды в валюту |
| **Карта** | Neon City: зоны, маркеры, позиции игроков, перемещение между районами |
| **Кошелёк** | Вонлонги на листе и в кошельке стола, переводы, выдача мастером |
| **Инвентарь** | Каталог предметов, экипировка, **использование расходников** с эффектами на лист |
| **Vault** | Файлы сценария: раздача, разблокировка игрокам, глобальный vault |
| **Персонажи** | Листы игроков, пресеты мастера, публикация заготовок |
| **Кибер** | Магазин имплантов, сборка, установка, Blood Tox, выдача игрокам и NPC |
| **Сценарий** | Узлы сюжета, связи с зонами/NPC/vault, прогресс по веткам |
| **Транспорт** | Транспорт стола (машины, дроны) — каталог Cyberpunk-транспорта |
| **МАСТЕР** | Инструменты ведущего (см. ниже) |
| **Заметки** | Личные заметки игрока по сессии |

### Панель мастера (VTT-уровень)

- **Схема боя** — тактическая карта, токены игроков и врагов, пресеты расстановки; боевики подтягиваются из БД стола.
- **Кубики** — броски d4–d100 в чат с подписью мастера.
- **Статусы** — conditions на листах (опьянение, ранения, баффы); объявление в чат; стек и эскалация по правилам домена.
- **Генерация** — быстрое создание игроков / NPC / боевиков: имена по происхождению, клички по деятельности, пул из 60+ предысторий, выбор навыков из пула класса.

### Правила внутри продукта

Встроенный **справочник C2185** с вкладками: основное, жизнь, экономика, бой, киберпсихоз, среда, классы — не нужно листать PDF во время сессии.

### Экономика и предметы

- Единый каталог `shared/nri-item-catalog.json` — оружие, броня, расходники, импланты, транспорт.
- Эффекты расходников и наркотиков — `shared/nri-consume-effects.json`; логика **одинакова на клиенте и сервере** (`shared/nri-domain/`).
- API использования предмета: сервер валидирует и пишет состояние листа — читы с клиента не проходят.

### Лор и мир стола

- Редактор лора, фракции, места, мировой текст сценария.
- Привязка сценарных узлов к карте, NPC и файлам vault.

## Платформа и технологии (для инвестора / техлида)

| Слой | Стек |
|------|------|
| Frontend | React 19, TypeScript, Vite 8, CSS-тема neon-services |
| Backend | Express 5, REST `/neon_v1`, JWT + bcrypt |
| Данные | Prisma 7 + SQLite (zero-cost старт; миграция на Postgres — по плану в ARCHITECTURE) |
| Контент | TS-модули мира + JSON-каталоги в `shared/` |
| Качество | Vitest (115+ тестов): домен, каталог, HTTP integration |
| Деплой | Один процесс: API + статика; `npm run build:full` → `npm start` |

**Архитектурный акцент:** общий домен NRI (`conditions`, `consume`) вынесен в `shared/nri-domain/` — один источник правды для браузера и Node. Это снижает рассинхрон правил и упрощает вынос API в отдельный сервис позже.

Подробности: [ARCHITECTURE.md](./ARCHITECTURE.md), технический долг: [SOLID_AUDIT.md](./SOLID_AUDIT.md).

## Для кого этот продукт

1. **Мастера настольных RPG** — готовый стол с картой, листами, кубиками и экономикой C2185.
2. **Игровые комьюнити** — один URL для кампании: не собирать зоопарк из сервисов.
3. **Образовательные и корпоративные форматы** — coop-режим как геймифицированный тренажёр ролей в разработке (Admin/Dev/QA/PM).
4. **Инди-студии и авторы контента** — модульный мир и JSON-каталоги без перекомпиляции клиента для баланса предметов.
5. **Хостинг-площадки** — легковесный деплой без обязательного managed PostgreSQL на старте.

## Текущий статус (Alpha)

**Работает сегодня**

- Три режима на входе (Session Gate): Solo / Coop / NRI.
- Полный цикл NRI: создание стола → join → чат → лист → инвентарь → карта → мастерские tools.
- Solo: модульный мир, sync прогресса, карточный бой.
- Coop: миссии полигона, рейтинги, ролевые колоды.
- CI-уровень: `npm test`, `npm run build`, валидаторы мира.

**Ограничения / следующий шаг**

- Крупные модули (`nriService`, `useGameState`, coop-роуты в `createApp`) — в процессе разрезания; домен кооп-матчей уже в `server/coop/`.
- Coop **presence** (кто онлайн в лобби) — in-memory с TTL ~50 с; это нормально для heartbeat.
- Серверная валидация PATCH sheet (статусы мастера) — в бэклоге.

## Метрики масштаба контента (ориентиры)

- **~20** модулей мира на карте (районы + хаб + спец-зоны).
- **6** классов Carbon 2185, **27** навыков, расширенный справочник правил.
- **Каталог предметов** — сотни позиций в JSON (оружие, кибер, расходники, транспорт).
- **75+** API-операций NRI на клиенте (`nriApi.ts`).
- **115+** автотестов на критичную логику.

## Дорожная карта (кратко)

1. **Стабилизация NRI** — разрез `nriService`, серверная валидация статусов мастера, OpenAPI/Zod-контракты.
2. **Coop persistence** — вынести live-матчи из in-memory в БД или Redis.
3. **Прод-данные** — Postgres / persistent volume для SQLite на хостинге.
4. **Контент** — новые районы, сценарии столов, пакеты предметов без форка движка.
5. **Монетизация (опционально)** — премиум-столы, косметика, сезонные рейтинги coop/NRI.
