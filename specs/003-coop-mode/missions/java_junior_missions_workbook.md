## Миссия `BANK-JU-001` — сумма операций за день

**Ранг:** junior  
**Бизнес-смысл:** посчитать итог дневных операций по уже подготовленному списку сумм.

### Текст для игрока (коротко)

Тебе дан список сумм операций клиента за **один день**. Нужно вывести **сумму всех элементов**. Если список **пустой**, вывести **`0`**.  
Парсинг файла и база данных **вне задачи** — список уже есть в `main`.

### Пример решения (Java, учебный)

```java
package com.bank.daily;

import java.math.BigDecimal;
import java.util.ArrayList;
import java.util.List;

public class DailySum {
  public static void main(String[] args) {
    List<BigDecimal> amounts = new ArrayList<>();
    // данные за день подставлены «за кадром» учебного стенда

    if (amounts.isEmpty()) {
      System.out.println(0);
      return;
    }

    BigDecimal total = BigDecimal.ZERO;
    for (BigDecimal x : amounts) {
      total = total.add(x);
    }
    System.out.println(total);
  }
}
```

## Сомнения и улучшения

- **Сомнение:** шаг ТЗ с двумя допустимыми `cardId` не гарантирует **педагогический** порядок (например `syntax_class_decl` на шаге «PACKAGE»). Лучше либо сузить пары до осмысленных, либо переименовать шаги под семантику.  
- **Улучшение:** для джуна добавить в UI миссии **мини-псевдокод** (3–6 строк) рядом с рельсой — как в переписке с игроком.  
- **Улучшение:** отдельный флаг миссии `strictStepSemantics: true` запрещает «левые» альтернативы на критичных шагах.  
- **Сомнение:** `deckRamMb` снаружи боя задаёт базу; без инфры длинная цепочка может не проходить `slotsOk` — в ТЗ миссии явно писать «нужен стенд админа».
