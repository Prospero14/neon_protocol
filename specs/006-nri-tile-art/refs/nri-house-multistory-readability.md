# Как читать многоэтажку сверху (NRI house tops)

Проблема: **чистый zenith-roof = «пол/платформа»**, не дом. Высота почти не передаётся одной крышей.

## Что говорят рефы / практика

| Источник | Идея |
|---|---|
| [saint11 — Top Down Houses](https://www.patreon.com/posts/top-down-houses-17397188) | **Fake perspective**: крыша + полоска фасада с окнами; низ PNG = «лицо». Тайлится, но даёт объём. |
| Pixel Architect / Chef RPG ([App2top](https://app2top.com/game_development/how-to-design-a-city-for-a-game-with-a-view-from-above-tips-from-an-architectural-designer-195671.html)) | Жильё сверху читается через **этажность фасада** (2–3 пояса окон), магазин внизу / квартиры сверху; «стерильная» карта убивает жизнь. |
| City / apartment packs (balconies, fire escapes, tanks) | Жилой код: **балконы**, пожарные лестницы, цистерны, бельё, AC — маркеры «здесь живут люди». |
| Реальные жилмассивы сверху | **Дворы-колодцы**, сегментированные секции крыши, повторяющиеся bay’и — сразу «панельки», не сарай. |

## Рекомендация для NRI (совместимо с поворотом 90°)

Карта крутит клетку целиком → **низ спрайта = фасад** ок: после поворота «лицо» едет вместе с ротацией.

```text
┌─────────────────────────┐
│  тонкий тротуар (кольцо)│
│  ┌───────────────────┐  │
│  │ КРЫША (70–80%)    │  │  ← AC, цистерны, антенны, бельё
│  │ сегменты / bay’и  │  │
│  └───────────────────┘  │
│ ████ ФАСАД 2–3 этажа ███│  ← окна рядами, балконы, неон-вывеска
│ ░░░ тротуар / двор ░░░░░│     (холодная палитра, без дороги)
└─────────────────────────┘
```

### Обязательные сигналы «жилмассив»

1. **Полоска фасада** снизу (не весь ¾ iso — тонкая, ~15–22% высоты клетки).
2. **2–3 горизонтальных пояса окон** на фасаде (этажность).
3. **Балконы / кондиционеры на фасаде** + rooftop clutter.
4. **Секции крыши** (не один гладкий прямоугольник) — как панельки рядом.
5. Опционально **внутренний двор-колодец** на 2×2 мега — массив читается ещё сильнее.
6. Дороги / разметка — **только procedural**, не в PNG.

Попап остаётся **¾ iso** (объём целиком). Карта — **roof + fake façade strip**.

## Анти-паттерны

- Крыша на всю клетку без фасада → «техплощадка».
- Сильный cyan bloom / тёплый sodium на крыше.
- Уникальная уличная диорама с разметкой → ломает стыки соседей.
