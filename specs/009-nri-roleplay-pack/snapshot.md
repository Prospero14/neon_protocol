## Кратко

Пока четвёрка съезжалась в **«Голубой диод»**, союз **НьюМета** + **Оракл-тек** накрыл **ИЦ 2z\*** (слив от **сотрудника 2z\***: топливо+двигатель → космос и отрыв). НьюМета разгромила центр, выпытала: архив в головах четверых → ориентировки и штурм клуба **копами**. Оракл-тек бьёт юридически (совет директоров). Копы куплены НьюМетой, молчат **сутки**. В разрушенном ИЦ можно найти сливщика **умирающим и сожалеющим**.

**«Друг»** — ячейка из НьюМеты, **перекупленная Оракл-тек**: в обход сделки Мета↔Оракл добыть архив и сдать в **ИЦ Оракл-тек**, у которого выход на **государство** (вернуть влияние, попиленное корпами). Доки через сутки = их окно.

На бегах: след, таймер, внешность, наличка, андерсити; ~12ч лица на проекторах. **MacGuffin:** 4 чипа → сборка через нейропротоколы + цепочку дока. **Фред:** «космос» = подхваченный слух; **АВК** запустила и ловит на живца (фиксеры просто гоняют инфу); архив → АВК → гос; спалить в андерсити = бой / тяжёлый разговор. **ВСЛ:** чужие доки часто закупаются у них; при апгрейде видят свежий чип → доклад; ВСЛ не знает что это, просто хватает инициативу в хаосе — улучшавшиеся у чужих спалятся.

## Развёрнуто

### Рамка

| | |
|--|--|
| Формат | Налёт на ИЦ + клуб → побег → сутки → доки (+ сборка архива) |
| Дедлайн | Сутки молчания копов = сутки до эвакуации «друга» |
| Партия | 4 ПК × 1/4 архива в головах |
| «Друг» | Перекупленная ячейка НьюМеты → Оракл-тек; цель — архив в ИЦ Оракл-тек → государство |
| Названо | «Голубой диод»; копы; НьюМета; Оракл-тек; 2z\*; трансхьюманы / Фред Крайст |
| Без имён | доки, квартал |
| NPC | При создании — тег `neutral` / `gang` / `corp` / `official`; большинство встреч — массовка, не уникалы |

### Параллель: налёт на ИЦ 2z\*

1. Слив разработки и масштаба отрыва — **сотрудник 2z\***.
2. Союз: **НьюМета** (сила) + **Оракл-тек** (юрфронт).
3. НьюМета громит ИЦ, узнаёт про четвёрку → ориентировки / штурм клуба.
4. Оракл-тек: блок процессов, свой в совет директоров 2z\*.
5. Копы под НьюМетой молчат **сутки**, потом вынуждены реагировать.

### «Друг» / Оракл-тек / государство

Официальная договорённость союза Мета↔Оракл ≠ цели ячейки.

Ячейка («друг») должна **в обход** этих договорённостей:
- забрать архив у ПК;
- доставить в **исследовательский центр Оракл-тек**;
- дальше — канал на **государство**, которое хочет вернуть влияние, забранное корпорациями.

Игрокам это неизвестно на старте; снаружи — только сообщения и эвакуация с доков.

### Акт I — «Голубой диод»

Входы: встреча / друзья / флаер / таксист. Uncanny + андроиды/голограммы. «Друг» → детектив: 3 мин, собери троих, кухня → доки через сутки. Штурм — копы.

### Акт II — сутки на бегах

След, внешность, наличка, андерсити. Таймер. ~12ч — лица на ориентировках / в машинах / на проекторах. Инфопро → НьюМета, «особо опасные».

**Ловушка апгрейда:** улучшение у чужого дока (подполье / официалка) → часто цепочка к **ВСЛ** → видят следы недавней операции (чип) → доклад. ВСЛ не понимает природу чипа, просто пытается вписаться в хаос. Свои силы / без чужого осмотра — безопаснее.

Если ВСЛ получила инфу → **открывает свою охоту**; сложность растёт (ещё один преследующий). Шкала эскалации — TBD.

### MacGuffin

Топливо + двигатель → космос; 4 чипа. Дека → чужое устройство → нейропротоколы → софт → 4 части → аппаратура дока → архив + физкопия.

### Корпорации и сила

| Кто | Роль |
|-----|------|
| **2z\*** | Жертва налёта; архив в ПК; заявления в полицию без ответа |
| **НьюМета** | Сила союза; разгром ИЦ; ориентировки; подкуп копов; «родная» корп ячейки до перекупа |
| **Оракл-тек** | Юрфронт союза; перекупила ячейку; ИЦ → государство |
| **Государство** | Хочет вернуть влияние через канал Оракл-тек |
| **АВК** | AI; в схеме Фреда — покупатель архива с перепродажей государству |
| **ВСЛ** | Медсеть; многие доки закупаются втихую; ищет «что-то» в хаосе, не знает кого; чужой апгрейд → замечают чип → доклад → спал носителя |

### Уличные / андерсити

**Трансхьюманы** + **Фред Крайст**: alien-хирургия, мессы, космос + «переход»; Иисус — инопланетянин.

**Секрет Фреда:** «откровение» = **слух АВК на живца**, дошедший по фиксаторским сетям (не агенты, не «на него вышли»). Под прессингом 1-на-1 (трусоват) признает, что не космос. Повестка коммуны: добыть архив → **АВК** → гос → «первые в межзвёзды».

Если партия спалит архив: **бой** или **переговоры (очень сложно)**.

Два гос-канала: **Оракл-тек** («друг») и **АВК** (слух → Фред).

### Предыстории ПК ↔ 2z\*

Детектив / нетраннер / наёмник / док — окна импланта через офис, оформление, медосмотр, «лечение» у ИЦ.

### Теги NPC (контент-правило)

Большинство встреч — массовка с тегом принадлежности:

| Тег | Смысл |
|-----|--------|
| `neutral` | нейтралы |
| `gang` | банды |
| `corp` | корпорации |
| `official` | официалы (копы, гос, бюро) |

Сюжетные NPC — поверх / отдельно; корп-тег можно уточнять кодом (ВСЛ, АВК, …) позже.

### Сайд / возврат в ИЦ

Пробраться в разгромленный ИЦ 2z\* «что с нами сделали» → находят **сливщика**: умирает, сожалеет (имя/полный мотив ещё открыты).

### Открытые дыры

- имя и полный мотив сливщика;
- имена доков, квартала;
- кто именно в АВК крутит слух / живец; знают ли они уже про четвёрку или ловят вслепую;
- шкала охоты ВСЛ после доклада (как именно повышается сложность; захват / вскрытие / перепродажа?);
- свой док-ПК: может ли безопасно апгрейдить остальных без спала;
- андроиды/голограммы в клубе;
- узнают ли ПК, что «друг» = Оракл-тек / госканал, до доков или после;
- конфликт ячейки с «честным» крылом НьюМеты / Оракл-тек, если вскроется обход сделки;
- столкновение каналов Оракл-тек vs АВК→гос, если оба активны;
- что после передачи архива vs сборки физкопии партией.
