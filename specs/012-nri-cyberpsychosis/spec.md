# 012 — Киберпсихоз (метрики, энкаунтер, шрамы)

## Problem

Blood Tox на листе есть, но нет накопительной метрики психоза от хрома + статусов (алкоголь, нарко, усталость, боль), нет истории эпизодов и мастерского ритуала «звонок → живой чат → продолжение».

## Principles

1. **База от имплантов** — `bloodToxCurrent` и превышение лимита задают floor стресса.
2. **Статусы двусторонние** — активные conditions дают `psychosisStress` (боль/нарко ↑, анальгезия/Lukolite ↓). Снял боль — PS упал сам.
3. **Купирование** — лекарства (`removeConditions` + relief-статусы), −BT (Lukolite), **отключение имплантов** (BT↓ → chrome floor↓). `syncPsychosisFlags` сбрасывает pending ниже порога.
4. **Шрамы копятся** — каждый завершённый энкаунтер поднимает `psychosisScarLevel` (постоянный дебаф; лекарствами шрам не снимается).
5. **Эпизод = сцена мастера** — порог только готовит; исход после «звонка» в личку.
6. **Merge sheet** — история/шрамы в `player.sheet`, sanitize массива истории.

## Metrics

| Поле | Смысл |
|------|--------|
| `psychosisStress` (computed) | BT-база + статусы + вклад шрамов |
| `psychosisScarLevel` 0…5 | Копящийся дебаф после эпизодов |
| `psychosisHistory[]` | Прошлые эпизоды |
| `psychosisPending` | Стресс ≥ порога эпизода |
| `psychosisEncounter` | Активный «звонок» мастера |

Пороги (glance): 20 нестабилен · 40 критичен · **60 эпизод**.

## Master UX

1. Вкладка **МАСТЕР → Психоз**: бары/спарклайны всей пачки, tier, история выбранного игрока.
2. **Позвонить** → `psychosisEncounter.active` + системное сообщение + **всплывающий live DM** (`NriDmCallPopup` через `neon:open-dm` с `popup: true`). Не требует открытой вкладки «Чат».
3. **Завершить энкаунтер** → history+, scar++, сброс pending/encounter; стресс падает к chrome-floor (шрамы остаются).

## Player UX

Баннер «входящий психоз-звонок» на время encounter.
На **игроцком** листе **нет** блока киберпсихоза и разбора кибер-эффектов (GM-only: `gmView` на листе мастера). Игрок видит импланты/BT/статусы, но не шкалу PS и не список hooks.
