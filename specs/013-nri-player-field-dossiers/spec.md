# Spec: NRI — вкладка «Персонажи» для игрока + полевые досье

> Игрок видит свой чарник и ведёт ручные карточки встреченных людей (без генерации и статов).  
> Связано: [004-nri-table](../004-nri-table/spec.md) · [009 inbox](../009-nri-roleplay-pack/inbox.md)

---

## Проблема

Вкладка **ПЕРСОНАЖИ** сейчас только у мастера (генерация, ростер, НПС, боевики).  
Игроку нужен свой раздел: **только свой лист** + возможность завести **пустые макеты-досье** на людей со стола (имя, принадлежность, важность, вещи, приметы) — без кубиков и без статов Carbon.

## Решение

| Актор | Вкладка «Персонажи» |
|-------|---------------------|
| **Мастер / админ** | Как сейчас: Генерация / Чарники / НПС / Боевики |
| **Игрок** | Две подвкладки: **Мой чарник** · **Досье** |

### Мой чарник

- Только лист текущего игрока (read-only просмотр листа; правки имени/бэкстори остаются у мастера).
- Чужих игроков не видно.

### Досье (полевые карточки)

Свободные текстовые поля, без статов и без генерации:

| Поле | Пример |
|------|--------|
| Имя | Пётр |
| Принадлежность | банда Серебряных Глаз |
| Важность | топ / важный / массовка… |
| Вещи | пистолет |
| Приметы | тату на лице |
| Заметки (опц.) | свободный текст |

- Карточки **личные**: видны только автору (как `privateNotes`), не мастеру и не другим игрокам.
- Хранение: JSON-массив `fieldDossiers` на `NriPlayer`.
- API: `PUT /neon_v1/services/nri/:code/player/field-dossiers` — полная замена списка (санитизация id/строк, лимит).

## Не входит

- Публикация досье мастеру / общий пул НПС.
- Генерация, рандом, статы, инвентарь-каталог на карточках.
- Редактирование чужого чарника игроком.
