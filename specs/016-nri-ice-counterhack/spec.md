# 016 — ICE Counter-Hack + Кибердека

## Цель

1. На **провале** ICE — тематический штамп (ICE отбил, IP перехвачен, QRF и т.д.).
2. После **5–7** подряд неудачных попыток взлома у игрока — стол входит в **встречный взлом**: таймер + попап игрокам и мастеру.
3. Мини-игра защиты: противник строит цепочки доступа к деке; игроки собирают **цепочки команд** из пула (~10 на этап).
4. Проигрыш встречного взлома → **дека приходит в негодность** (предмет удаляется) + финальное сообщение «звук полицейских сирен».
5. **Кибердека** — предмет (несколько уровней) в каталоге/магазинах; всё ICE/нетраннерское через деку — только при наличии деки в инвентаре; деку можно передать.

## Порог

`ICE_COUNTERHACK_THRESHOLD = 6` (в диапазоне 5–7). Считается `consecutiveFails` на sheet игрока (уже есть в `nriIceBan`).

При достижении порога:

- стартует `iceCounterHack` на sheet игрока (+ host alert мастеру);
- UI: попап с таймером у игрока и индикатор у мастера.

## Встречный взлом

- `endsAt` — дедлайн (по умолчанию ~90 с).
- 3 этапа; на каждом пул из ~10 команд, нужно выбрать **верную цепочку** (2–3 команды в порядке).
- Параллельно растёт `enemyProgress` 0…100 (визуал «противник собирает доступ»).
- WIN: progress сброшен, fails обнулены, дека цела.
- FAIL (таймер / enemy 100% / неверные цепи исчерпали попытки): удалить все предметы с тегом `deck` из инвентаря; stamp «сирены»; hardware ban.

## Дека

Каталог:

| id | уровень |
|----|---------|
| `g_cyberdeck` | базовая (уже есть) |
| `g_cyberdeck_mid` | рабочая |
| `g_cyberdeck_pro` | mil-spec |
| `g_left_deck` | clearance / «левая» (уже есть) |

Тег `deck`. `hasDeck(inventory)` — любой catalogId с тегом или whitelist id.

Гейт: старт ICE-аркады / vault icebreaker — только с декой (**исключение: мастер/хост** может играть без деки).

Передача: обычный инвентарный transfer (как любой gear).

## Out of scope

- Реальный audio siren file (достаточно текста/штампа; звук опционально позже).
- PvP counter-hack между столами.
